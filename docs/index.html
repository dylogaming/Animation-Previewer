Unreal Engine 5 · Editor Utility Widget

Animation Previewer

Click any animation in the Content Browser. It plays instantly in a built-in preview.

  • No room setup
  • Free-fly camera
  • Works with Realtime off
  • Editor only actors

Setup

1. Run the widget

Right-click EUW_AnimationPreviewer and choose Run Editor Utility Widget. Dock it anywhere.

It opens as a tab.

Found in Content/AnimationPreviewer. The preview room spawns by itself.

2. Click animations

Select any Anim Sequence or Montage. It plays right away.

Interface

Hover a label to find it. Click a box to read about it.

  1. Locked Mesh Pin a mesh so every animation plays on it.
  2. Preview Live view of the selected animation.
  3. Quick buttons Reset Mesh, Reset Camera, open the widget, open the room.
  4. View modes Lit, Unlit, Wireframe, Lighting Only, Sky.
  5. Play / Pause Also bound to Space.
  6. Timeline Drag to scrub any frame.
  7. Time Current and total seconds.
  8. Animation details Rotation, offset, floor, sequence, montage, attachments, root motion.
  9. Skeleton compatibility Share animations across skeletons.

Features

View modes

Switch shading from the bottom left of the preview. Sky toggles the backdrop.

Rotate

Set Actor Rotation to face the mesh any way. Or use Alt + Wheel.

Offset and floor

Feet sinking into the floor? Raise Z in Actor Offset. It moves the mesh in room space.

Uncheck Show Floor? to hide the floor.

Attachments

Pick a Attachment Preset to equip props. Edit sockets and meshes in Attach Mesh.

Your mesh needs the matching sockets. Presets: None, Sword, Sword & Shield, Rifle, Pistol.

Root Motion Lock

Root Motion Lock keeps moving animations in place. Turn it off to see the real travel.

Skeleton compatibility

Play UE4 animations on UE5 meshes, and the reverse.

  1. Bones for Compatibility Bones two skeletons must share.
  2. Link This / Link All / Delete All Link this skeleton, link every match, or clear all.
  3. Compatible Skeletons Skeletons linked to the current one.

Lock Mesh

Check Lock Mesh to keep the current mesh. Every animation you click then plays on it.

Link the skeletons first. Lock while the mesh you want is showing.

Layout and scale

Drag the dividers to resize panels. Ctrl + Shift + Wheel scales the details.
